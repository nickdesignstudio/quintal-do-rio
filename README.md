# Quintal do Rio

### Landing Page — Restaurante Brasileiro com Jeito Carioca

Landing page conceitual desenvolvida para o **Quintal do Rio**, um restaurante fictício inspirado na gastronomia brasileira e no estilo descontraído do Rio de Janeiro.

O projeto foi criado com foco em **Web Design, experiência do usuário, responsividade e desenvolvimento Front-End**, buscando transmitir uma identidade visual acolhedora, moderna e autêntica.

---

## Sobre o projeto

O **Quintal do Rio** é um projeto fictício desenvolvido para simular a presença digital de um restaurante brasileiro.

A proposta da landing page é apresentar o restaurante de forma clara e visualmente atrativa, conduzindo o visitante por uma experiência que passa pela identidade do estabelecimento, cardápio, ambiente, ocasiões de visita e informações de localização.

O projeto foi pensado como uma **landing page comercial**, priorizando:

- Clareza das informações
- Hierarquia visual
- Navegação intuitiva
- Apresentação dos pratos
- Identidade visual consistente
- Experiência em dispositivos móveis
- Chamadas para ação (CTAs)

---

## Objetivos

O projeto teve como principais objetivos:

- Criar uma landing page completa para um restaurante fictício
- Desenvolver uma identidade visual coerente com a proposta da marca
- Apresentar o cardápio de maneira visual e organizada
- Criar uma experiência responsiva para diferentes tamanhos de tela
- Aplicar conceitos de UI/UX
- Desenvolver uma página utilizando tecnologias Front-End fundamentais

---

## Estrutura da página

### Hero

Apresentação inicial do restaurante, sua proposta de valor e principal chamada para ação.

### Destaques

Apresentação dos principais diferenciais do Quintal do Rio:

- Comida brasileira
- Preço justo
- Clima carioca

### Cardápio

Exibição dos principais pratos da casa, incluindo nome, descrição, imagem e preço.

### O Quintal

Seção institucional apresentando o conceito e a atmosfera do restaurante.

### Ocasiões

Seção direcionada a diferentes situações de consumo:

- Almoço sem complicação
- Encontro com os amigos
- Reunião em família

### Localização

Apresentação das informações de contato, endereço e horário de funcionamento.

### CTA Final

Chamada final para incentivar o visitante a conhecer o restaurante e consultar o cardápio.

### Footer

Rodapé com navegação, informações de contato e identificação do projeto como conceitual.

## Design e UI/UX

O projeto utiliza uma abordagem visual baseada em:

- Layout limpo e organizado
- Hierarquia tipográfica
- Espaçamento consistente
- Cards para apresentação dos pratos
- Seções bem definidas
- Contraste adequado entre conteúdo e fundo
- CTAs estrategicamente posicionados
- Design responsivo
- Fotografia como elemento principal de comunicação

A interface foi pensada para transmitir uma sensação de **proximidade, simplicidade e autenticidade**, alinhada à proposta de um restaurante brasileiro com influência carioca.

---

## Responsividade

A landing page foi desenvolvida para se adaptar a diferentes dispositivos e tamanhos de tela.

O layout contempla:

- Desktop
- Tablet
- Smartphone

A estrutura dos conteúdos, imagens, cards e elementos de navegação é adaptada conforme o espaço disponível.
